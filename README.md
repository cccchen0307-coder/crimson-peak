# Crimson Peak｜緋紅之巔

一款以繁體中文製作的 2D 點擊式心理懸疑解謎遊戲原型。

## 已完成內容

- 開始畫面與五章流程
- 祖父房間、舊檔案館、研究場所、願望商店、緋紅之巔五個場景
- 點擊調查熱點、對話選擇與劇情轉場
- 道具欄與線索筆記
- 第一章「被移動的書」完整排序謎題
- 第二章檔案時間線謎題
- 第三章紅色符號因果謎題
- 第四章不完整契約謎題與交易選擇
- 第五章真正願望、循環與三種結局
- 純 HTML / CSS / JavaScript，無需建置工具或後端

## 執行方式

直接以瀏覽器開啟 `index.html` 即可遊玩。也可以使用任何靜態網站伺服器，例如：

```bash
python3 -m http.server 8000
```

再開啟 <http://localhost:8000>。

## 操作方式

點擊場景中的標籤調查物件；在右側切換「道具」與「線索」；完成謎題後依照對話提示進入下一章。錯誤操作不會導致永久卡關。

## 注意

目前場景美術使用 CSS 抽象氛圍圖形，方便先測試完整玩法與流程。後續可以將 `scene-art` 替換成正式 2D 背景、音效與動畫。
